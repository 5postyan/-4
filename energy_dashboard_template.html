Энергобаланс объектов

Сколько каждый объект потратил из сети и сколько продал обратно. По данным счетов за весь период и по телеметрии за последние недели.

Добавить данные объекта

Добавьте файлы объекта вместе

Выберите несколько файлов сразу в одном окне. Архив создавать не нужно.

1Положите в одну папку object.json, invoice.csv и telemetry.csv.
2В окне выбора файлов отметьте все нужные файлы, удерживая Ctrl.
3Нажмите кнопку ниже. Программа создаст объект и пересчитает отчёты.

Нужен паспорт object.json. CSV можно добавить сейчас или позже. Исходные данные не изменяются.

Точечная загрузка одного файла (для исправлений)

CSV можно дополнить новыми временными метками или заменить целиком. Исходная папка не изменяется.

Для добавления загрузите только новые строки с теми же заголовками и без повторяющихся меток времени.

Потрачено — энергия, полученная из сети (отбор по счёту, подтверждённые значения; где их нет — исходные). Продано — энергия, отданная в сеть. Отрицательные значения и явные выбросы исключены из сумм, подробности в блоке «Ошибки в данных». Статусы этапов запуска взяты из результатов проверки (results.json).

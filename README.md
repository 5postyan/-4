# Энергобаланс объектов и карточка запуска

Локальное веб-приложение для просмотра энергобаланса объектов и проверки четырёх этапов запуска. Главная страница показывает графики, купленную и проданную энергию, а также ошибки и предупреждения. Ссылка **«Карточка запуска»** открывает подробные проверки.

Статусы рассчитываются по правилам из `rules.json`. Приложение не отправляет команды физическому оборудованию; проверки управления используют имитатор.

## Запуск на другом Windows-ПК без Docker

1. Установите **Python 3.10 или новее** с [python.org](https://www.python.org/downloads/windows/). При установке включите **Add python.exe to PATH**.
2. Установите [Git for Windows](https://git-scm.com/download/win), если Git ещё не установлен.
3. Откройте PowerShell и скопируйте эти команды. Git создаст папку `C:\EnergyDashboard` и загрузит туда программу:

   ```powershell
   git clone https://github.com/5postyan/-4.git C:\EnergyDashboard
   Set-Location C:\EnergyDashboard
   ```

4. Если у вас уже есть данные, скопируйте папки объектов (`Building1`, `Building2` и т. д.) в `C:\EnergyDashboard\data`. В папке объекта могут находиться `object.json`, `invoice.csv` и `telemetry.csv`. Этот шаг можно пропустить и загрузить объект через сайт.
5. Дважды щёлкните **`start_local.bat`**. При первом запуске скрипт создаст `.venv` и установит необходимые библиотеки. Для установки нужен интернет.
6. Откроется энергобаланс: **http://127.0.0.1:8001/energy.html**. Подробная карточка запуска доступна по ссылке вверху страницы. Если порт занят, приложение выберет следующий свободный и покажет адрес в окне запуска.
7. Чтобы закрыть приложение, нажмите **Ctrl+C** в окне батника.

Запускайте батник обычным двойным щелчком, не от имени администратора. Сервер доступен только на этом компьютере (`127.0.0.1`).

## Как добавить первый объект

1. На странице раскройте **«Добавить данные объекта»**.
2. Нажмите поле выбора файлов. Удерживая **Ctrl**, выберите файлы одного объекта: `object.json`, `invoice.csv` и `telemetry.csv`. Архив создавать не нужно. Для создания объекта обязателен `object.json`; CSV можно добавить позже.
3. Нажмите **«Загрузить и пересчитать»**. Приложение создаст папку следующего свободного объекта (`Building1`, `Building2` и далее), привяжет паспорт к номеру папки и пересоберёт обе страницы.

Для уже существующего объекта CSV можно дополнить новыми строками или заменить целиком; паспорт можно заменить. Исходные файлы в `data/` остаются без изменений. Загруженные файлы сохраняются в `added_data/` между запусками и не отправляются на GitHub.

Если вы заменили CSV или JSON непосредственно в папке `data/`, нажмите **«Перечитать CSV/JSON»** на странице энергобаланса или **«Перечитать файлы и обновить карточку»** в карточке запуска. Приложение повторно скопирует входы, пересчитает проверки и обновит обе страницы. Если для объекта есть и загруженная копия, и исходный файл, используется файл с более поздним временем изменения. Открытая в другой вкладке карточка обновится автоматически после пересчёта.

## Запуск в Docker

1. Установите и запустите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Клонируйте репозиторий командой выше. Если данные уже есть, скопируйте папки объектов в `data/`.
3. Дважды щёлкните **`start.bat`**. При первом запуске Docker скачает базовый образ и соберёт приложение; компьютеру нужен интернет.
4. Откройте **http://127.0.0.1:8000/energy.html**. Для остановки дважды щёлкните **`stop.bat`**.

Для Docker Python устанавливать не нужно. Входные файлы подключаются к контейнеру только для чтения; загрузки, результаты и логи сохраняются в папках проекта.

## Данные, результаты и ошибки запуска

- `data/` — исходные файлы объектов. Содержимое исключено из Git: паспорта могут включать адреса и EAN. В репозитории есть только пустой `.gitkeep`, поэтому первую папку можно создать загрузкой с сайта.
- `added_data/` — файлы, загруженные через страницу.
- `runtime_data/` — рабочие копии и временные файлы пересборки.
- `out/` — страницы `energy.html`, `index.html` и отчёты.
- `logs/application.log` — журнал запуска и проверок; строки исходных CSV в него не записываются.

Если окно запуска закрылось или страница не открылась, запустите `start_local.bat` из PowerShell, чтобы увидеть сообщение об ошибке. Проверьте установку командой `py -3 --version`. Если виртуальное окружение повреждено, удалите папку проекта `.venv` и запустите батник снова. При ошибке загрузки проверьте имена файлов и заголовки; подробность будет показана на странице.

## Основные файлы проекта

- `launch/` — парсер CSV/JSON, проверки, переходы этапов, загрузка файлов и веб-сервер.
- `rules.json` — пороги проверок.
- `energy_dashboard_template.html` и `dashboard_template.html` — шаблоны страниц.
- `run_demo.py`, `build_dashboard.py`, `build_energy_dashboard.py` — формирование результатов и страниц.
- `local_entrypoint.py` и `docker_entrypoint.py` — запуск без Docker и в контейнере.
